# LiveBall

A Windows desktop app (WPF, .NET 8) that lists live and upcoming NBA games and plays their streams in an embedded browser (WebView2).

## Features
- Live / Today game lists with team monograms and a LIVE badge
- Single and **Multi** mode (up to 4 streams at once, one audio source at a time)
- Collapsible sidebar and borderless fullscreen

## Requirements
- Windows 10/11

## Run
```
Run exe from release
```

## Shortcuts
| Key | Action |
| --- | --- |
| F11 | Toggle fullscreen |
| Esc | Exit fullscreen |
| Ctrl+B | Show / hide sidebar |

In fullscreen, move the mouse to the top edge to bring the toolbar back.

## Disclaimer
LiveBall is an unofficial client. It does not host, store or rebroadcast any video; it only displays third-party pages returned by the public [Streamed](https://streamed.pk/docs) API. You are responsible for making sure that what you watch is legal where you live. Not affiliated with the NBA or any team.
